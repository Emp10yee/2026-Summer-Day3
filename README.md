## 폴더 구조

## PR(Pull Request) 규칙

- 해당 repository를 fork해서 본인 이름으로 만든 폴더에서 작업하고 commit 후 Pull Request를 보냅니다.
- PR은 각 주차별 과제를 commit하여 보냅니다.
- 제목은 `[중급 1팀 1일차] 이름`으로 설정합니다.
  - ex) [중급 1팀 1일차] 홍길동
